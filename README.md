# OAI GEO NTN Experimental Evidence

Experimental evidence for a 5G NR Non-Terrestrial Network (NTN) study using OpenAirInterface.

## Experimental Scenarios

- GEO NTN with HARQ OFF
- GEO NTN with HARQ ON
- Clean HARQ-ON validation
- TCP diagnostic experiments

## Main Setup

- OpenAirInterface
- RF Simulator
- GEO propagation delay: 238.74 ms
- UE PDU session IP: 10.0.0.3
- EXT-DN: 192.168.70.135

## Evidence Included

- gNB logs
- UE logs
- OAI configuration files
- Ping measurements
- UDP UL/DL measurements
- TCP UL/DL measurements
- TCP socket traces
- Packet captures
- OAI commit information
- iperf3 version information
- SHA-256 checksums
